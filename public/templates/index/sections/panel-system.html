Audio backend strategy controls Rust-first auto mode or explicit Force Rust behavior.

Release checks run once when the server launches (if enabled). Use CHECK FOR UPDATES any time for manual checks.

APPLY UPDATE performs a non-destructive in-place update with backup/rollback and then requires server restart.

Set STARTUP UPDATE PROMPTS to disabled if you do not want update prompts; manual checks stay available.

Danger: disabling log redaction can expose usernames, client keys, bridge IDs, area IDs, bearer tokens, and network addresses in plain text logs.

Use API BASE if this UI runs on a different host than the bridge server.
