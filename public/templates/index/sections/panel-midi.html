ADVANCED MIDI MAPPING

Use this when learn mode grabbed the wrong control, when you need a specific channel, or when a knob should only trigger above a certain value.

If a knob or fader triggers too easily, raise TRIGGER THRESHOLD. For note/pad controls, a value of 1 usually means “press only, ignore release.”
